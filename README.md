**traceMark** é uma rede social focada em publicar imagens de fotógrafos autônomos que registram corridas de rua.

Projeto desenvolvido para o trabalho de nuvem.

## Como rodar

```bash
# install dependencies
npm install

# start dev server
npm run dev

# production build
npm run build

# preview production build
npm run preview
```
